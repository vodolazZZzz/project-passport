# Роли в пользователей в системе: 
## Клиент - возможности пользователя: 
1. Просмотр каталога продукции 
2. Ознакомление с составом продукции (На случай возможной аллергии 
на определённые компоненты) 
3. Сборка торта (Выбор состава коржей, крема, начинки, оформления, 
веса торта и т.п)
4. Оформление заказа (выбор доставки, выбор времени доставки, указание комментариев к заказу, выбор оплаты)
5. Отслеживание статуса заказа
6. Просмотр истории заказов
## Менеджер по продажам – возможности:
1.	Создание или редактирование заказа клиента
2.	Резервирование даты и времени производства
3.	Прикрепление промокодов и скидок к заказу
4.	Просмотр заказов
5.	Отправка рассылок
## Администратор – возможности: 
1.	Управление пользователями
2.	Внесение изменений (удаление товаром или их скрытие на время, редактирование цен и т.п)
3.	Просмотр всех заказов
4.	Управление поставщиками
5.	Настройка доставки
## Кондитер – возможности:
1.	Просмотр календаря с заказами на день\неделю
2.	Доступ к технологической карте
3.	Изменение статуса заказа: «В работе» → «Испечён» → «Собран» → «Готов»
4.	Отметка о нехватке ингредиентов (создание запроса кладовщику)
5.	Добавление комментариев по типу: «осторожно, торт скользкий, упаковать с подложкой»
## Кладовщик – возможности: 
1.	Введение складского учёта
2.	Создание заявок на закупку
3.	Приёмка товаров от поставщиков
4.	Списание ингредиентов по рецептуре
5.	Проведение инвентаризации
6.	Блокировка опции заказа если ингредиента нету в остатке
## Курьер – возможности:
1.	Просмотр маршрута заказа
2.	Отметка статуса: «Забрал у кондитера» → «В пути» → «Доставлен»
3.	Отчёт о доставке
## Бухгалтер – возможности:
1.	Просмотр финансовых отчётов
2.	Выгрузка в Excel
3.	Начисление зарплаты сотрудникам
## Гость – возможности:
1.	Ознакомление с каталогом продукции
2.	Возможность зарегистрироваться на сайте
# Пользовательский сценарий
## Заказ клиентом торта через конструктор
Главная страница → Каталог → Выбор категории «Торты» → Карточка товара «Собери свой торт» → Конструктор (выбор коржа, начинки, крема, декора, веса, надписи) → Корзина → Оформление заказа  → Оплата онлайн → Личный кабинет → Отслеживание статуса заказа.
## Обработка менеджером звонков и создание заказа клиента
Входящий звонок от клиента → Открытие панели менеджера → Поиск клиента по номеру телефона → Создание нового заказа → Выбор продукта из каталога → Проверка свободных слотов производства → Резервирование даты и времени → Отправка клиенту SMS со ссылкой на оплату → Изменение статуса заказа на «Подтверждён».
## Выполнение заказа кондитером
Вход в панель кондитера → Просмотр панели со списком заданий на сегодня → Открытие задания → Чтение технологической карты  → Отметка этапа «Готовится» →  Отметка этапа «Сборка и декор»  → Отметка задания как «Готово».
