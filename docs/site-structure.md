# Разрабатываемые страницы 
## Для клиента - клиент получает полноценный интернет-магазин. Он содержит в себе форму регистрации и входа, личный кабинет, главную страницу с навигацией по странице, акциями, меню со всей продукцией, контакты кондитерской, окно, где можно “собирать” торт, корзину для добавления интересующей продукции, окно для оформления заказа, окно для просмотра статуса заказа, окно с историей прошлых заказов. 
## Для менеджера - менеджер работает в специальной панели управления, которая недоступна клиентам. Панель управления менеджера содержит виджеты: количество новых заказов сегодня, количество заказов в обработке, сумма заказов за сегодня, список заказов на сегодня с отметкой о готовности, график загрузки производства на ближайшие дни. Также на дашборде отображаются пять последних обращений в чат и кнопка быстрого создания заказа со звонка.
## Для администратора - администратор имеет доступ ко всем разделам системы плюс дополнительные управленческие функции. Панель управления администратора — это панель ключевых показателей в реальном времени: выручка сегодня/месяц, количество заказов, средний чек, процент отмен, загрузка производства в процентах, общая себестоимость, топ-5 продаваемых продуктов, список последних действий пользователей (кто что изменил).
## Для кондитера - кондитер получает упрощённый интерфейс, оптимизированный для работы на планшете или большом смартфоне. Панель управления кондитера показывает сегодняшнюю дату, список заданий на сегодня в виде карточек по статусам: «Ожидают старта», «В работе», «Готово». Вверху отображаются срочные задания (желаемое время меньше, чем через 2 часа) и предупреждения о нехватке ингредиентов.
## Для курьера - курьер работает в мобильном веб-приложении, адаптированной под экран телефона. Панель управления курьера после входа в систему показывает сегодняшнюю дату, список назначенных задач (маршрутный лист), кнопку «Начать смену» (фиксирует время начала), кнопку «Завершить смену». Если задач нет, отображается сообщение «Сегодня доставок нет».
## Для кладовщика - кладовщик имеет доступ к складской панели. Панель управления кладовщика отображает критические остатки (ингредиенты, которые закончились или подходят к концу), список заявок от кондитеров (новые и в работе), поступления на сегодня (что ожидается от поставщиков), списания за сегодня.
## Для бухгалтера - бухгалтер имеет доступ к ограниченному набору страниц. Страница «Финансовые операции» показывает список всех платежей с фильтрацией по дате, статусу, способу оплаты, заказу.
